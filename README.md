# Exploratory Data Analysis on India's COVID-19 Data

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on India's COVID-19 dataset using Python.

The main aim of this project is to analyze COVID-19 data, identify important trends and patterns, and represent the findings through meaningful data visualizations.

The analysis is performed using Python libraries such as **Pandas, NumPy, Matplotlib, and Seaborn**.

---

## 🎯 Objectives

The main objectives of this project are:

- To understand the COVID-19 dataset.
- To clean and preprocess the data.
- To perform Exploratory Data Analysis (EDA).
- To analyze COVID-19 cases and their trends.
- To calculate important statistical measures.
- To analyze recovery and death-related information.
- To identify patterns and relationships between different variables.
- To create meaningful visualizations using Python.
- To summarize the important findings from the dataset.

---

## 🛠️ Technologies Used

- **Python**
- **Pandas**

- **Seaborn**
